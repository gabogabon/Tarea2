
Este repositorio contiene códigos fuente hechos en Python, en conjunto con la librería Tkinter

boton.py: Este programa contiene un label el cual da la bienvenida, seguido de un botón el cual al ser pulsado llama una función ubicada dentro del código fuente, esta función se encarga de colocar un texto dentro de un segundo label.

entrada.py: Este programa contiene de igual manera un label que da la bienvenida, además una entrada de texto la cual está configura para ocultar los caracteres que el usuario ingrese, esto simulando un login, y por último un botón el cual revela los caracteres ingresados por el usuario.

cajadetexto.py: Este programa contiene una caja de texto multilínea, la cual imprime el mensaje "Escribe aquí tu texto", seguido de un botón el cual al ser pulsado invoca un método el cual toma los caracteres ingresados por el usuario en la caja de texto y los imprime con un print en la consola
